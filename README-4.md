## 1. Часть 1. Бизнес-логика дата-центра (Функции, классы, коллекции)

В первой части домашнего задания требовалось реализовать две функции по варианту, активно используя методы строк, работу с объектами, коллекции и специфические циклы (не по счетчику).
Мы внедрили эту логику в виде класса `BillingManager`, который отвечает за применение скидок и проверку доступности IP-адресов в дата-центре.

### 1.1. Задание по варианту 1: Работа со строками (Проверка промокодов-палиндромов)

По заданию необходимо реализовать функцию проверки строк (например, на палиндром) для применения определенной бизнес-логики. В нашем случае мы внедрили механику "Секретных промокодов дата-центра": если клиент вводит промокод, который читается одинаково в обоих направлениях (палиндром), ему начисляется скидка на аренду Выделенных серверов.

Алгоритм включает очистку строки от пробелов и спецсимволов с помощью регулярных выражений, а затем реверс строки через массив:

```javascript
class BillingManager {
    constructor() {
        this.account = { account_number: "FV-00124", balance: 5000, discount: 0 };
        this.appliedPromos = new Set(); // Используем коллекцию Set для уникальности
    }

    // Функция проверки промокода на палиндром
    isValidPalindromePromo(promoCode) {
        // Очищаем строку от пробелов и приводим к нижнему регистру
        const cleanedString = promoCode.toLowerCase().replace(/[^a-z0-9]/g, '');

        if (cleanedString.length === 0) return false;

        // Переворачиваем строку
        const reversedString = cleanedString.split('').reverse().join('');

        return cleanedString === reversedString;
    }

    applyPromo(promoCode) {
        if (this.appliedPromos.has(promoCode)) {
            console.log(`Промокод ${promoCode} уже был использован.`);
            return;
        }

        if (this.isValidPalindromePromo(promoCode)) {
            this.account.discount = 15; // Даем скидку 15%
            this.appliedPromos.add(promoCode);
            console.log(`Скидка активирована для аккаунта ${this.account.account_number}!`);
        } else {
            console.log("Недействительный промокод.");
        }
    }
}
```
В данном коде успешно применяются строковые методы (`toLowerCase`, `replace`, `split`, `join`), работа со свойствами объектов (`this.account.discount`), а также коллекция `Set` для хранения уже использованных промокодов.

### 1.2. Задание по варианту 2: Использование множеств (Set) и цикла с постусловием

Второе задание требовало использования цикла с условием (не по счетчику, а по событию). В контексте дата-центра мы создали симулятор выделения свободного IP-адреса для нового виртуального сервера.
Пул доступных IP хранится в коллекции `Set`. Цикл `do-while` продолжает перебор пула до тех пор, пока не найдет рабочий и свободный IP-адрес.

```javascript
class ServerManager {
    constructor() {
        // Коллекция IP-адресов
        this.ipPool = new Set([
            { address: "192.168.0.1", status: "BUSY" },
            { address: "192.168.0.2", status: "OFFLINE" },
            { address: "192.168.0.3", status: "AVAILABLE" }
        ]);
    }

    allocateServerIp() {
        let allocatedIp = null;
        let iterator = this.ipPool.values();
        let currentItem = iterator.next();

        // Цикл с постусловием: ищем свободный IP-адрес
        do {
            if (currentItem.done) {
                console.error("Нет доступных IP-адресов для серверов!");
                break;
            }

            const ipObj = currentItem.value;
            if (ipObj.status === "AVAILABLE") {
                allocatedIp = ipObj.address;
                ipObj.status = "BUSY"; // Занимаем IP
            }

            currentItem = iterator.next();
        } while (allocatedIp === null);

        return allocatedIp;
    }
}
```
В данном примере цикл работает не по количеству итераций, а опирается на сложное бизнес-условие: `while (allocatedIp === null)` (пока адрес не будет найден).

## 2. Часть 2. Внедрение 3D-моделей с использованием Three.js

Во второй части домашнего задания необходимо было модифицировать страницу карточек услуг (в нашем проекте это `CatCardComponent`), чтобы вместе с информацией об услуге в отдельном блоке отображалась интерактивная 3D-модель (формат `.glb`), соответствующая тематике сайта.

Для дата-центра «FlowVector» была выбрана 3D-модель серверной стойки (`data_center_rack.glb`). Пользователь может вращать её прямо на странице выбора услуг.

### 2.1. Подключение библиотеки Three.js

Для работы с Three.js без сложных сборщиков, в файл `add/main.html` были добавлены Import Maps, которые позволяют напрямую загружать модули библиотеки с CDN (unpkg):

```html
<script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@0.160.0/build/three.module.js",
      "three/examples/jsm/": "https://unpkg.com/three@0.160.0/examples/jsm/"
    }
  }
</script>
```
В самом компоненте `add/components/cat-card/index.js` импортируются необходимые классы: базовая библиотека `THREE`, загрузчик `GLTFLoader` и контроллер мыши `OrbitControls`.

### 2.2. Инициализация базовых компонентов сцены

Метод `init3DModel(data)` вызывается сразу после добавления HTML-карточки в DOM-дерево. Он находит контейнер `div#3d-container-{id}` и инициализирует в нём сцену.

Для начала мы создаем **Сцену** (пространство для объектов), **Камеру** (то, как мы смотрим на сцену) и **Рендерер** (движок WebGL для отрисовки графики в Canvas):

```javascript
const container = document.getElementById(`3d-container-${data.id}`);

// 1. Сцена
const scene = new THREE.Scene();
scene.background = new THREE.Color('#212529'); // Темный корпоративный фон

// 2. Камера (Угол обзора 45 градусов, соотношение сторон контейнера)
const camera = new THREE.PerspectiveCamera(45, container.clientWidth / container.clientHeight, 0.1, 1000);
camera.position.set(0, 2, 5); // Отдаляем камеру по оси Z и Y

// 3. Рендерер
const renderer = new THREE.WebGLRenderer({ antialias: true }); // Сглаживание краев
renderer.setSize(container.clientWidth, container.clientHeight);
container.appendChild(renderer.domElement);
```

Чтобы модель не была черным пятном, на сцену добавляются источники света. `AmbientLight` дает базовое освещение со всех сторон, а `DirectionalLight` имитирует свет лампы с определенного угла, создавая красивые тени на серверной стойке.

### 2.3. Загрузка GLB-модели серверной стойки

Для загрузки модели используется `GLTFLoader`. Поскольку модели могут иметь произвольный размер (одна стойка может быть смоделирована высотой в 1 единицу, а другая в 1000 единиц), был написан универсальный алгоритм автоматического масштабирования и центрирования.

```javascript
const loader = new GLTFLoader();
const modelUrl = '../../models/data_center_rack.glb';

loader.load(modelUrl, (gltf) => {
    const model = gltf.scene;

    // Вычисляем виртуальную коробку (Bounding Box), охватывающую модель целиком
    const box = new THREE.Box3().setFromObject(model);
    const center = box.getCenter(new THREE.Vector3());
    const size = box.getSize(new THREE.Vector3());

    // Сдвигаем модель так, чтобы ее центр оказался в координатах (0,0,0) сцены
    model.position.sub(center);

    // Находим максимальную сторону (высоту, ширину или глубину)
    const maxDim = Math.max(size.x, size.y, size.z);

    // Масштабируем так, чтобы модель занимала ровно 2.5 единицы измерения
    const scale = 2.5 / maxDim;
    model.scale.set(scale, scale, scale);

    scene.add(model); // Добавляем выровненную модель на сцену
});
```
Этот код гарантирует, что любая скачанная из интернета `.glb` модель будет красиво и пропорционально отображаться внутри карточки услуги.

### 2.4. Настройка управления и анимации

Чтобы модель была интерактивной, используется плагин `OrbitControls`. Он перехватывает движения мыши внутри Canvas и соответствующим образом вращает камеру вокруг объекта.

Чтобы стойка плавно крутилась сама по себе, когда пользователь ничего не делает, включено свойство `autoRotate`. Вся отрисовка зацикливается с помощью системной функции браузера `requestAnimationFrame`, которая синхронизирует частоту кадров рендера с частотой обновления монитора (обычно 60 FPS).

```javascript
const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true; // Плавное затухание вращения
controls.enableZoom = false;   // Отключаем зум, чтобы мышь скроллила саму страницу
controls.autoRotate = true;    // Включаем автоматическое медленное вращение
controls.autoRotateSpeed = 2.0;

// Бесконечный цикл отрисовки
const animate = () => {
    requestAnimationFrame(animate); // Запланировать следующий кадр
    controls.update();              // Обновить координаты для autoRotate
    renderer.render(scene, camera); // Вывести кадр на экран
};
animate();
```
